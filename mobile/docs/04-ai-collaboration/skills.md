## 2. تفاصيل المهارات وإرشادات الاستخدام

### 2.1 مهارة NativePHP for Mobile:
* فهم دورة حياة تطبيق الموبايل الأصلي المبني بـ Laravel و NativePHP.
* استدعاء الـ Native APIs الخاصة بالهواتف (الإشعارات، الكاميرا، التخزين، النوافذ، الحوارات).
* تشغيل واختبار التطبيق عبر `php artisan native:run` و `php artisan serve`.

### 2.2 مهارة المعاملات والحسابات المالية الصارمة (Financial & Decimal Precision):
* استخدام `DECIMAL(12,3)` لكل الأرقام والكميات.
* عدم استخدام عمليات الحساب التقليدية (`+`, `-`, `*`, `/`) مع القيم المالية واستبدالها بـ:
  * `bcadd()`, `bcsub()`, `bcmul()`, `bcdiv()`, `bccomp()`.
* حساب متوسط التكلفة المرجح: `Average Cost = (Total Value + New Value) / (Total Qty + New Qty)`.

### 2.3 مهارة حماية التزامن والمخزون (Concurrency & Locking):
* تنفيذ كافة عمليات البيع، الشراء، المرتجعات، والتحويلات داخل:
  ```php
  DB::transaction(function () {
      $item = Item::where('id', $itemId)->lockForUpdate()->first();
      // تحقق من الرصيد وخصم المخزون
  });
  ```

### 2.4 مهارة تصميم وتجربة شاشات اللمس والموبايل (Touch UI & Design Tokens):
* الالتزام بألوان Blade الأصلية: الزمردي `#10b981`، العنبري `#f59e0b`، والداكن `#020617`.
* تطبيق فئات Tailwind المنطقية للتوافق مع العربية RTL.
* تصميم عناصر تفاعلية بارتفاع لا يقل عن 48px لتسهيل الاستخدام بالإبهام.

### 2.5 مهارة الطباعة الحرارية ومشاركة الفواتير (Thermal Printing & Export):
* إعداد وتنسيق قوالب الطباعة الحرارية بعرض 80mm و 58mm.
* دعم تصدير الفواتير وكشوف الحسابات واليومية كـ PDF لمشاركتها عبر تطبيقات المراسلة.
