## 2. الخطوط والطباعة العربية (Typography & Fonts)

* **الخطوط المعتمدة:** `Cairo` و `Tajawal` (عبر Google Fonts).
* **الأوزان (Weights):**
  * `300` / `400`: نصوص الشروحات والتفاصيل الفرعية.
  * `600`: أسماء الأصناف، العناوين الفرعية، وحقول البحث.
  * `700` / `800`: إجماليات المبالغ المالية، أرقام الفواتير، والأزرار الكبيرة.
* **الأحجام التناسبية للموبايل (Mobile Sizing):**
  * إجمالي الفاتورة الكبير (POS Grand Total): `text-3xl font-extrabold` (30px).
  * عناوين الشاشات: `text-xl font-bold` (20px).
  * أسماء الأصناف في القوائم: `text-base font-semibold` (16px).
  * الأسعار والكميات: `text-sm font-bold` (14px).
  * التواريخ والملاحظات: `text-xs` (12px).

## 3. معايير تجربة المستخدم لشاشات اللمس (Mobile UX & Touch Targets)

1. **الارتفاع القياسي للأزرار وحقول الإدخال:**
   * الحد الأدنى لمنطقة اللمس: **`h-12` (48px)** لضمان سهولة الضغط بالإبهام أثناء البيع السريع.
   * الأزرار السريعة داخل أسطر الفاتورة: **`h-10` (40px)**.
2. **شريط التنقل السفلي (Bottom Navigation Bar):**
   * بار سفلي مثبت يحتوي على الأيقونات الرئيسية: (الرئيسية، الكاشير POS، الأصناف، العملاء، التقارير).
   * ارتفاع البار: `h-16` (64px) مع دعم منطقة الأمان (Safe Area Inset).
3. **الاتجاه العربي المنطقي (RTL Guidelines):**
   * الاعتماد الكامل على الفئات المنطقية (`ms-*`, `me-*`, `ps-*`, `pe-*`, `text-start`, `text-end`).
   * الأرقام والأسعار محاذاة جهة اليسار (`text-end`) لسهولة قراءة الفواصل العشرية.
   * أسماء الأصناف والنصوص محاذاة جهة اليمين (`text-start`).
4. **شاشات التحميل والتغذية الراجعة (Feedback & Skeleton Loading):**
   * شريط تحميل علوي متحرك متدرج (Glow Loading Bar) بألوان `#d97706` و `#10b981`.
   * إشعارات عائمة سريعة (Toast Messages) تختفي تلقائيًا بعد 3 ثوانٍ عند الحفظ أو الاعتماد.
